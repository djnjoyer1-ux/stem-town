IMAGE INBOX

To create an image post, put BOTH files here:

example.jpg
example.txt

The .txt file must have the same base filename as the image.

Example example.txt:

A hand-drawn free-body diagram of a block on a 30-degree incline.
Gravity is decomposed into mg sin(theta) along the incline and
mg cos(theta) normal to the surface. A friction force points uphill.

The local language model does NOT inspect image pixels.
It receives only the text description.

When WAKE_TOWN.bat runs:
1. the image becomes the main post,
2. the sidecar text is stored as image_alt,
3. random personas comment underneath based on that description.
